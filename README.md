# GreenCut — Сайт компании по покосу травы

Профессиональный одностраничный коммерческий сайт для компании по механизированному покосу высокой травы и расчистке заросших территорий в Грузии.

## Как открыть

Просто откройте файл `index.html` в браузере двойным кликом.

## Что нужно заменить перед публикацией

| Место в коде | Что заменить |
|---|---|
| `+995XXXXXXXXX` | Реальный номер WhatsApp |
| `+995 XXX XXX XXX` | Реальный номер телефона |
| `info@greencut.ge` | Реальный email |
| `GreenCut` | Название вашей компании (если отличается) |

## Структура файлов

```
grass service/
├── index.html          — основной HTML-файл сайта
├── css/
│   └── style.css       — все стили (CSS переменные, компоненты, адаптив)
├── js/
│   └── main.js         — интерактивность (навигация, форма, анимации)
└── images/             — папка для фотографий (добавьте свои)
```

## Разделы сайта

1. **Hero** — главный экран с заголовком и кнопками
2. **Услуги** — 3 карточки услуг
3. **Техника** — интерактивные вкладки с оборудованием
4. **Преимущества** — 6 карточек УТП
5. **Галерея** — сравнение до/после
6. **Как работаем** — 4 шага
7. **Форма заявки** — с валидацией
8. **Контакты** — карточки + WhatsApp CTA
9. **Footer** — навигация и контакты

## Как подключить форму к Telegram/Email

Замените в `js/main.js` строку симуляции отправки:
```js
await new Promise(r => setTimeout(r, 1200));
```
на реальный `fetch()` к вашему бэкенду или сервису (Formspree, EmailJS и т.д.).

## Настройка Formspree (бесплатно)

1. Зарегистрируйтесь на [formspree.io](https://formspree.io)
2. Создайте форму, получите endpoint вида `https://formspree.io/f/XXXXXXX`
3. В `index.html` добавьте атрибут к `<form>`: `action="https://formspree.io/f/XXXXXXX" method="POST"`
