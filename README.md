# GreenCut — Сайт компании по покосу травы

Профессиональный одностраничный коммерческий сайт для компании по механизированному покосу высокой травы и расчистке заросших территорий в Грузии.

## Как открыть

Просто откройте файл `index.html` в браузере двойным кликом.

## Что нужно заменить перед публикацией

| Место в коде | Что заменить |
|---|---|
| `+995XXXXXXXXX` | Реальный номер WhatsApp |
| `+995 XXX XXX XXX` | Реальный номер телефона |
| `info@greencut.ge` | Реальный email |
| `GreenCut` | Название вашей компании (если отличается) |

## Структура файлов

```
grass service/
├── index.html          — основной HTML-файл сайта
├── css/
│   └── style.css       — все стили (CSS переменные, компоненты, адаптив, языковой переключатель)
├── js/
│   ├── translations.js — словарь переводов (русский, грузинский, английский)

└── images/             — папка для фотографий (добавьте свои)
```

## Мультиязычность (RU / KA / EN)

Сайт поддерживает 3 языка:
- 🇷🇺 **Русский (RU)** — язык по умолчанию
- 🇬🇪 **Грузинский (KA / ქართული)** — профессиональный перевод с поддержкой шрифта Noto Sans Georgian
- 🇬🇧 **Английский (EN)** — международная версия для экспатов и бизнеса

### Особенности реализации
1. **Переключатель в шапке (Desktop):** стильный выпадающий список с флагами, индикатором активного языка и мягкой анимацией.
2. **Переключатель в мобильном меню:** удобные сегментированные кнопки-пилюли в верхней части мобильного меню.
3. **Переключатель в подвале:** быстрые текстовые ссылки внизу страницы.
4. **Сохранение выбора:** выбранный язык сохраняется в `localStorage` и в URL (`?lang=ka`, `?lang=en`, `?lang=ru`).
5. **Автоопределение языка:** при первом визите язык определяется автоматически по браузеру пользователя.
6. **Полная локализация:** переводятся не только тексты, но и плейсхолдеры формы, валидационные ошибки, метатеги, `title`, `og:title`, `aria-label`, а также предзаполненное сообщение в WhatsApp.
7. **Работа без сервера:** работает как на хостинге, так и локально при открытии `index.html` через `file:///`.

### Как изменить или добавить переводы
Все тексты хранятся в файле [`js/translations.js`](file:///c:/Users/Сергей/Desktop/grass%20service/js/translations.js). Вы можете легко изменить любую фразу в соответствующей секции `ru`, `ka` или `en`.

## Как подключить форму к Telegram/Email

Замените в `js/main.js` строку симуляции отправки:
```js
await new Promise(r => setTimeout(r, 1200));
```
на реальный `fetch()` к вашему бэкенду или сервису (Formspree, EmailJS и т.д.).

## Настройка Formspree (бесплатно)

1. Зарегистрируйтесь на [formspree.io](https://formspree.io)
2. Создайте форму, получите endpoint вида `https://formspree.io/f/XXXXXXX`
3. В `index.html` добавьте атрибут к `<form>`: `action="https://formspree.io/f/XXXXXXX" method="POST"`
